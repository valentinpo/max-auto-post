# MAX авто-постинг

Скрипт автоматической публикации постов с картинками, текстом и кнопками
в каналы мессенджера MAX по расписанию. Включает веб-панель для управления.

## Возможности

- 📷 Посты с картинками (загрузка через API MAX)
- 🔘 Кнопки: ссылки (link) и callback
- ⏰ Расписание по времени, дате и дням недели
- 📚 Несколько каналов — для каждого поста выбираете свои
- 🖥 Веб-панель (localhost:3001): управление постами/каналами, лог, загрузка картинок
- 🛰 Автопоиск каналов по событиям бота

## Как настроить

1. **Установить зависимости**
   ```
   npm install
   ```

2. **Добавить токен бота** — скопируйте файл `.env.example` в `.env`:
   ```
   copy .env.example .env
   ```
   Впишите реальный токен бота MAX (business.max.ru → Чат-боты → ваш бот → Настройки → токен).

3. **Настроить каналы** — в `config/channels.json` укажите `chat_id` своих каналов.
   Бот должен быть администратором в каждом канале.

   **Как получить chat_id канала:**
   - Откройте канал в веб-версии MAX — в адресной строке будет URL вида
     `https://web.max.ru/-12345678901234`. Число после дефиса — это chat_id.
   - **Важно:** ID каналов/групп в MAX отрицательные (с минусом),
     например `-12345678901234`. Без минуса API вернёт ошибку `chat.not.found`.
   - Либо добавьте бота в новый канал при запущенной панели — она сама
     поймает событие `bot_added` и добавит канал в конфиг.

4. **Заполнить расписание** — в `config/schedule.json` пропишите посты:
   - `time` — время публикации (например "09:00"), применяется часовой пояс из `timezone`;
   - `date` — (необязательно) конкретная дата `YYYY-MM-DD`, если пост нужен один раз;
   - `days` — (необязательно) дни недели массивом: `[1,3,5]` = пн,ср,пт (1=пн..7=вс);
   - `channels` — список каналов (по имени из channels.json или напрямую chat_id);
   - `media` — путь к картинке относительно папки проекта (кладите в `contents/`);
   - `text` — текст поста;
   - `buttons` — кнопки: с `url` — внешняя ссылка, без url — callback-кнопка.

## Запуск

### Режим планировщика (без панели)
```
npm start
```
Скрипт работает постоянно: раз в 30 секунд проверяет, не наступило ли время
очередной публикации, и отправляет посты во все указанные каналы.

### Веб-панель управления (рекомендуется)
```
npm run panel
```
Откройте в браузере: **http://localhost:3001**

Панель позволяет:
- запускать/останавливать постинг;
- управлять постами (добавлять, редактировать, удалять, отправлять немедленно);
- управлять каналами (добавлять/удалять chat_id);
- загружать картинки в `contents/` прямо из браузера и выбирать их в посте;
- видеть живой лог событий (SSE).

## Примечания

- **Windows:** для работы с API MAX может потребоваться отключить проверку
  сертификатов Node: `set NODE_TLS_REJECT_UNAUTHORIZED=0` (уже добавлено в
  `start-panel.bat` / `start-panel.ps1`). Это локальный хак для разработки.
- Картинки загружаются через API загрузки MAX (тип image), затем отправляются
  по токену. Поддерживаются JPG/PNG/WebP и др., до 50 МБ.
- Кнопки `link` открывают внешние URL (можно использовать UTM-ссылки).
- Если пост загружается дольше — скрипт ждёт 3 секунды перед отправкой
  (рекомендация API: файл должен "дозреть").
- Максимум 30 запросов/сек к API — скрипт работает значительно медленнее, это ок.

## Безопасность

- Файл `.env` с токеном добавлен в `.gitignore` — никогда не коммитьте его.
- Не публикуйте токен бота и chat_id каналов в открытых репозиториях.
